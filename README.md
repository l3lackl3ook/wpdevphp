# WordPress Development - GrowFox Marketing

Repository นี้รวบรวม WordPress themes และ plugins ที่พัฒนาสำหรับ GrowFox Marketing

## 📦 ส่วนประกอบ

### 🎨 Themes
- **hello-elementor-child** - Child theme สำหรับ Hello Elementor พร้อมฟังก์ชันดึงข้อมูลอัตราแลกเปลี่ยนจาก ธปท.

### 🔌 Plugins
- **thailand-financial-data-plugin** - Plugin สำหรับดึงข้อมูลทางการเงินจาก Make.com (อัตราแลกเปลี่ยน, ราคาทอง, ราคาน้ำมัน)
- **growfox-rest-api** - Plugin ใช้ ACF เก็บข้อมูลพร้อม Elementor Dynamic Tags และ Widgets

### 📁 Extras
- ไฟล์เสริมต่างๆ เช่น ACF fields และ scripts

## 📚 เอกสาร

อ่านคู่มือการใช้งานฉบับสมบูรณ์ได้ที่: [WORDPRESS_THEME_PLUGIN_GUIDE.md](WORDPRESS_THEME_PLUGIN_GUIDE.md)

## 🚀 การติดตั้ง

### Theme
1. ไปที่ WordPress → Appearance → Themes → Add New → Upload Theme
2. เลือกโฟลเดอร์ `hello-elementor-child`
3. Activate theme

### Plugins
1. ไปที่ WordPress → Plugins → Add New → Upload Plugin
2. เลือกโฟลเดอร์ plugin ที่ต้องการ
3. Activate plugin
