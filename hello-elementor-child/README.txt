=== Hello Elementor Child Theme - Professional Edition ===
ระบบดึงข้อมูลอัตราแลกเปลี่ยนจาก ธปท. + การออกแบบที่สวยงามและเป็นมืออาชีพ

🎨 คุณสมบัติการออกแบบ:
✅ Typography สวยงามด้วย Google Fonts (Sarabun)
✅ Responsive Design ที่ทำงานได้ดีบนทุกอุปกรณ์
✅ Animations และ Transitions ที่ลื่นไหล
✅ Modern Card Layout สำหรับโพสต์
✅ Gradient Colors และ Shadows ที่ทันสมัย
✅ Reading Progress Bar
✅ Scroll to Top Button
✅ Image Lightbox
✅ Social Share Buttons
✅ Related Posts Section
✅ Reading Time Display
✅ Breadcrumbs Navigation
✅ Copy Code Button สำหรับ Code Blocks
✅ Lazy Loading Images
✅ SEO Meta Tags

📊 คุณสมบัติอัตราแลกเปลี่ยน:
✅ ดึงข้อมูลจาก ธปท. อัตโนมัติ
✅ อัปเดตทุกวัน
✅ แสดงตารางสวยงามพร้อมธงประเทศ
✅ รองรับ Mobile (Responsive)

📦 วิธีติดตั้ง:
1. อัปโหลดไฟล์ zip ผ่าน Appearance → Themes → Add New → Upload Theme
2. คลิก Install Now และ Activate
3. ไปที่ อัตราแลกเปลี่ยน → อัปเดตข้อมูล
4. คลิก "อัปเดตข้อมูลทันที"
5. ใช้ shortcode [bot_exchange_rates] ในหน้าที่ต้องการ

🎯 การใช้งาน:
- หน้าโพสต์จะมี Reading Time, Share Buttons, และ Related Posts อัตโนมัติ
- หน้า Archive จะแสดงโพสต์ในรูปแบบ Grid Card ที่สวยงาม
- มี Scroll to Top Button และ Reading Progress Bar
- รูปภาพสามารถคลิกเพื่อดูแบบ Lightbox
- Code blocks มีปุ่มคัดลอกโค้ด

💡 เคล็ดลับ:
- ใช้ Featured Image สำหรับทุกโพสต์เพื่อความสวยงาม
- เขียนเนื้อหาที่มีคุณภาพ ระบบจะคำนวณเวลาอ่านอัตโนมัติ
- ใช้ Categories เพื่อให้ Related Posts ทำงานได้ดี

📱 รองรับ:
- Desktop (1920px+)
- Laptop (1024px - 1919px)
- Tablet (768px - 1023px)
- Mobile (< 768px)

🔧 ความต้องการ:
- WordPress 5.0+
- Hello Elementor Theme
- Elementor Plugin (แนะนำ)
- PHP 7.4+
