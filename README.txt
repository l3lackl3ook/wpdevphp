=== WordPress Theme และ Plugins Export ===

📦 ไฟล์ที่ export มา:

1. hello-elementor-child/ และ hello-elementor-child.zip
   - Child theme สำหรับ Hello Elementor
   - ดึงข้อมูลอัตราแลกเปลี่ยนจาก ธปท.

2. thailand-financial-data-plugin/ และ thailand-financial-data-plugin.zip
   - Plugin สำหรับดึงข้อมูลทางการเงินจาก Make.com
   - รองรับ: อัตราแลกเปลี่ยน, ราคาทอง, ราคาน้ำมัน

3. growfox-rest-api/ และ growfox-rest-api.zip
   - Plugin ใช้ ACF เก็บข้อมูล
   - มี Elementor Dynamic Tags และ Widgets

4. extras/ และ wordpress-extras.zip
   - ไฟล์เสริมต่างๆ (ACF fields, scripts)

5. WORDPRESS_THEME_PLUGIN_GUIDE.md
   - คู่มือการใช้งานฉบับสมบูรณ์

🚀 วิธีติดตั้ง:

สำหรับ Theme:
1. ไปที่ Appearance → Themes → Add New → Upload Theme
2. เลือกไฟล์ hello-elementor-child.zip
3. คลิก Install Now และ Activate

สำหรับ Plugins:
1. ไปที่ Plugins → Add New → Upload Plugin
2. เลือกไฟล์ .zip ของ plugin ที่ต้องการ
3. คลิก Install Now และ Activate

📖 อ่านคู่มือเพิ่มเติม:
เปิดไฟล์ WORDPRESS_THEME_PLUGIN_GUIDE.md
